Was das NoahBuilds Dashboard ist

Das NoahBuilds Dashboard ist ein privates Programm, das nur auf dem Computer von NoahBuilds läuft. Es wird ausschließlich für die eigenen Konten von NoahBuilds genutzt und ist für niemanden sonst bestimmt.

Welche Daten verarbeitet werden

  • Über die YouTube Data API und die YouTube Analytics API: Kanalname, Abonnentenzahl, Aufrufe, Wiedergabezeit, Videos und die Kommentare unter den eigenen Videos.
  • Über die Schnittstellen von Instagram, TikTok und Pinterest: entsprechende Statistiken, Beiträge und Kommentare der eigenen Konten.
  • Antworten auf Kommentare werden nur auf ausdrücklichen Klick hin gesendet.

Speicherung und Weitergabe

Alle Daten und Zugangsschlüssel werden nur lokal auf dem Computer von NoahBuilds gespeichert. Es gibt keinen Server, keine Weitergabe an Dritte, keine Werbung und keinen Verkauf von Daten. Daten aus Google-APIs werden nur für die Anzeige im Dashboard genutzt.

Die Nutzung von Informationen, die über Google-APIs empfangen werden, hält sich an die Google API Services User Data Policy, einschließlich der Anforderungen zur eingeschränkten Nutzung (Limited Use).

Linkseite

Auf der Linkseite werden Aufrufe und Klicks auf die Link-Knöpfe anonym gezählt, auf einem eigenen Server von NoahBuilds. Gespeichert werden nur Zeitpunkt, Herkunftsseite (zum Beispiel Instagram), angeklickter Knopf und Gerätetyp (Handy oder PC). Es werden keine Cookies gesetzt, keine IP-Adressen gespeichert und keine Daten an Dritte weitergegeben.

Zugriff widerrufen

Der Zugriff lässt sich jederzeit unter myaccount.google.com/permissions beziehungsweise in den Einstellungen der jeweiligen Plattform entziehen. Lokal gespeicherte Daten werden dann gelöscht.

English summary

NoahBuilds Dashboard is a private tool that runs only on NoahBuilds' own computer and is used only for NoahBuilds' own accounts. It reads channel statistics, posts and comments via the official APIs and replies to comments only when explicitly asked. All data and tokens stay on that computer; nothing is shared, sold or used for ads. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The link page counts visits and button clicks anonymously on NoahBuilds' own server (time, referring site, button, phone or PC only), without cookies and without storing IP addresses. Access can be revoked at any time at myaccount.google.com/permissions. Contact: Noahbuilds@icloud.com.
